# Booking in Monaco

A booking website I built where users can explore and book apartments, homes, yachts, events, and hotels in Monaco.

## Features

- Landing page with an overview of Monaco and available booking categories
- Explore section showcasing apartments, yachts, homes, events, and hotels
- Booking form collecting name, username, email, phone number, date, guest count, booking type, and special requests
- Pricing section listing rates for each category
- Embedded Google Maps location of Monaco
- Contact section with a message form
- Responsive layout for mobile screens

## Built With

- HTML
- CSS
- Font Awesome (icons)
- Google Fonts (Poppins)
- Google Maps embed

## Getting Started

1. Clone the repository
2. Open `website.html` in your browser

No installation or dependencies required — it's a static site.
